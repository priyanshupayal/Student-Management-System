# Student Management System

A simple CRUD (Create, Read, Update, Delete) application built with Node.js, Express.js, PostgreSQL, HTML, CSS, and JavaScript.

## Features

* Add new students
* View all students
* Update student details
* Delete student records
* PostgreSQL database integration
* Input validation
* Duplicate email prevention

## Tech Stack

* Node.js
* Express.js
* PostgreSQL
* HTML
* CSS
* JavaScript
